# The briefs of level 1 — examples

The six briefs that level 1 (`ams`) was painted, corrected and ported from, as they were given to the helper
agents on 2026-11-10 and 2026-11-11. Use them as the pattern for a new brief (`docs/LEVEL_GUIDE.md`, "Working
with helpers"). They are records: their paths name the working copy of that time (`tmp/l1/kit`, `tmp/l1/port`).
The kit now lives in `tools/levelkit/` (commands in its README).

| File | What it briefed | Why it is worth reading |
|---|---|---|
| `1-paint-section.md` | paint one section in the kit on the game's layout | the base brief of a painter: the camera, the files it owns, "done when" |
| `2-scale-pass.md` | scale all scenery to the hero | the scale rule and its table; what does not scale |
| `3-street-audit.md` | audit and fix the walk band of a section | the street grammar; the full audit with strips; lead notes per section |
| `4-port-engine.md` | build the engine path for baked scenes | decisions table, architecture, the bake contract, engine facts |
| `5-port-section.md` | port one section and pair its entities with the art | the pairing step, the look step, the gates per section |
| `6-fix-one-fault.md` | fix one fault class in several sections | the report, the measured cause, a binding rule, a gate added with the fix |

Passes 2, 3 and 6 were repairs. A new level gives its painters those rules from the start (`../look.md`, "The
grammar"), so it does not need them.
